The specification behind Meridian

A protocol is not an application, so it sits on its own. Meridian above is its reference implementation.

MMSP Specification MultiMedia Subscription Protocol: a community specification for feeds that carry video, audio, articles, images, releases and events in one JSON format, defined as a semantic superset of RSS 2.0 and Atom. Pull-only with a 300-second poll floor, so calm consumption is a property of the wire rather than a setting. Ships normative JSON Schemas and a conformance suite that mirrors the draft section by section.
