Commercial licensing

Every application here is free and open source; that does not change. A commercial licence is a separate agreement for anyone the open licence does not suit.

I wrote and own the code in each project below, so I can license it on terms other than its open-source licence. A commercial licence takes nothing away from anyone using the open one. It is a second route to the same code, agreed in writing.

When you might want one

  • You want to ship the code (or a modified version of it) inside a closed-source product.
  • Your organisation does not allow GPL or LGPL code in what it distributes.
  • You want terms an open licence cannot give, such as a warranty or support.

When you do not need one

Using these applications needs nothing from me, whether at home or inside a company. The GPL and the LGPL attach their conditions to distributing the software rather than to running it. If you only use it, the open licence already covers you.

This page describes the licences in plain terms. It is not legal advice.

What a commercial licence covers

My own code in the project you name. Third-party components keep the licences their authors gave them, whatever we agree:

  • The Python desktop applications use PySide6 (Qt for Python) under the LGPL-3.0. Its conditions still apply to it; The Qt Company sells its own commercial licence for Qt.
  • Stellody's packaged build bundles an FFmpeg build that includes GPL components; those stay under the GPL.
